# VSM 页面请求优先级，4096 / 256 页池

已保留生产改动。请求按用途标记，同一页面的多个角色通过原子 OR 合并；角色由几何覆盖与目标混合决定，不随当前驻留情况变化。

实际顺序为：**终层与紧邻主层的父层保底 → 主采样 → 其余过渡请求 → 更深的兜底链**。保底组内部从粗到细，所以终层先取得页面。需要混合的首个父层同时带过渡标记；无混合时仍保留这一跳父层，避免主采样过载后直接退到终层。之后的备用层不再挤占主采样和过渡页面。淘汰先比较用途优先级，再比较最近请求时间；同类请求保留从粗到细和同层驻留保护。

原先只把主采样提前的版本没有保留：主请求 312 页已超过 256 页池，虽明显减少回退，却挤掉所有过渡/中间兜底，静帧出现 5,699 个诊断采样点直退 L9。该失败对照保存在 `aggressive-summary.json`。

**分配性能优化**：64 个线程并行快照本帧请求，用 32 KiB 组共享位图记录遍历顺序，随后串行部分只遍历实际请求。位图覆盖最大 16 层 × 128 × 128 页，共 262,144 页。不增加 GPU buffer、dispatch 或 C# 渲染热路径。池已满时跳过重复空槽搜索。保留页面物理槽身份、时间戳、溢出计数和诊断快照语义。

## 场景结果

场景为 VividRP_Reborn / Sponza，Camera_1，1920×1080，固定 4096、256 页、首层 0、屏幕密度目标 1、过渡 0.2、9 比较 PCF、随机滤波关闭。保留 NativeAA TSR、16 历史样本和原锐化设置。质量捕获使用临时固定曝光，结束后已恢复相机、灯光、Volume、时间和后台运行设置。

每阶段清空页池，预热至少 128 帧并对齐 jitter；每版本静止 32 帧，转动 128 帧（前 96 帧 ±12°，后 32 帧停住）。静止帧全捕获；转动每 4 帧及最后一帧捕获，因此不能宣称排除了所有未捕获的瞬态。

静帧 0，按最终反馈角色与两个版本的有效页面集合求交集。角色可以重叠，不能相加作为总数：

| 页面用途 | 请求数 | 原版本驻留 | 最终驻留 |
|---|---:|---:|---:|
| 主采样 | 312 | 165 | 191 |
| 过渡 | 93 | 76 | 93 |
| 紧邻父层 | 128 | 107 | 128 |
| 终层 | 2 | 2 | 2 |

各层驻留从 `[0,0,0,106,95,34,13,4,2,2]` 改为 `[0,11,11,116,88,26,2,0,0,2]`。静帧 0 全屏诊断采样的主层回退比例由 58.38% 降至 47.51%。32 个静帧中，每帧 18,107～21,548 个诊断点使用更细层，没有点变粗；转动捕获帧中每帧 16,422～28,946 点变细，变粗点峰值 491，没有新增无可用层，也未观测到 L9 采样或整帧 CSM 回退。

屋檐和拱门的大部分接收面仍选择 L4，目标轮廓的锯齿仍受细层覆盖范围约束。该改动解决页面分配挤占，不能凭这些数据宣称解决了全部锯齿。总请求没有减少，静止峰值仍 421 页，转动峰值仍 438 页；溢出主要转移到低优先级需求。

位图优化前后，在 65 个同姿态、同 jitter 捕获帧中，有效页面集合与实际采样层全部一致。63 帧原始阴影 ROI 完全一致；另 2 个静帧分别有 307、328 个边缘像素不同（ROI 共 364,000 像素），最大差异 0.184814。没有将其归因于某个已确定原因，也没有把时间重建输出差异当作准确性证明。详见 `compaction-equivalence.json`。

## 性能与验证

沿用已有 VSMBaselineSession，固定相机，5 秒预热、5 秒测量，不做逐帧图像读回。GPU marker 与整帧时序含 Editor / 其他相机影响，整帧时间未严格归属到单一相机；这些数值不能直接与用户之前的 7.3 ms 测量等同。记录器因页池溢出等条件标记 `completed_with_warnings`，不代表严格的性能认证。

| 版本 | 样本数 | 分配阶段中位 ms | 整帧 GPU 中位 ms |
|---|---:|---:|---:|
| 原版本 | 434 | 5.857 | 11.436 |
| 优先级改动、未做遍历优化 | 333 | 8.835 | 15.050 |
| 最终版本 | 805 | 0.487 | 5.907 |
| 最终版本复测 | 945 | 0.398 | 5.223 |

最终性能收益主要来自避免全表重复扫描和满池空槽搜索，不能全部归功于角色优先级。GPU Resolve marker 原版本约 1.875 ms，最终首次约 2.084 ms；更多细页可用后采样工作的变化仍有成本。

- 隔离 Direct3D12 GPU 检查：541 项通过，涵盖冷池、角色 OR、父层保底、淘汰顺序、连续帧稳定性、过期反馈、frame 0、双向所有权、清理，以及 64 / 8192 / 262144 页的位图边界。
- DXC：35 个生产及采样测试 kernel 全通过。
- Roslyn：Runtime、Editor、Tests 三个程序集编译通过，源文件与 Bee response 快照稳定。
- 清理后 Unity 控制台：收尾时间窗内 0 个错误。临时脚本、Shader 和自动生成的 meta 已移除；场景与 AA 设置已核对恢复。
